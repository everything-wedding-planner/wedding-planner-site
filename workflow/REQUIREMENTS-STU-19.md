# STU-19: Vendor Management Page - Admin Dashboard

## Problem
Companies (vendors/venues) need a centralized page within the admin dashboard to manage their vendor listings, update vendor details, and see performance metrics (inquiries and bookings) for each vendor.

## Desired Outcome
A page where companies can view all their vendors, edit vendor details, add new vendors, and see inquiry/booking counts per vendor at a glance.

## Scope
**In scope:**
- Display list of vendors associated with the company
- View vendor details (name, service type, contact name, email, phone)
- Edit vendor details
- Add new vendor
- Show inquiry count per vendor
- Show booking count per vendor

**Out of scope:**
- Public-facing vendor pages (separate feature)
- Vendor analytics beyond counts
- Bulk operations on vendors
- Delete functionality
